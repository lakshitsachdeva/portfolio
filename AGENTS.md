## Project Summary
A high-end minimalistic portfolio website for Lakshit Sachdeva, a CS student and ML/Full-Stack enthusiast. The site features a dark theme, Helvetica typography, and interactive components like PixelBlast, PixelCard, ClickSpark, and BlurText.

## Tech Stack
- Framework: Next.js 15 (App Router, Turbopack)
- Styling: Tailwind CSS 4, Lucide React
- Animations: Framer Motion, Three.js, Postprocessing
- UI Components: Custom React Bits (PixelBlast, PixelCard, ClickSpark, BlurText, SpotlightCard)
- Database: Supabase (PostgreSQL)

## Architecture
- `src/app/page.tsx`: Main portfolio page with resume data.
- `src/components/react-bits/`: Interactive UI components from user-provided snippets.
- `src/app/globals.css`: Dark theme and Helvetica font configuration.
- `src/lib/supabase.ts`: Supabase client configuration.

## User Preferences
- Minimalistic black aesthetic with subtle accents.
- Typography: Helvetica.
- Use of React Bits components (PixelBlast, PixelCard, ClickSpark, BlurText).
- Functional components, no unnecessary comments.

## Project Guidelines
- Keep it minimalist and "so good".
- Default to dark mode.
- Use Helvetica as the primary font.

## Common Patterns
- Subtle background effects (PixelBlast).
- Interactive cards (PixelCard).
- Micro-interactions (ClickSpark, BlurText).
